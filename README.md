# Used Car Price Prediction

**Shadrach Oboh | C00298390**

This portfolio explores used car prices and compares Linear Regression, Decision Tree and Random Forest models. It uses the [CarDekho vehicle dataset](https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho). The notebook assumes the original prices are in Indian rupees and converts them to US dollars at a fixed exchange rate.

The Random Forest achieved a test mean absolute error of approximately **$780** and an R² score of **0.931**.

The repository includes the notebook, dataset, work diary and three-slide presentation.

## Run the notebook

Install the required packages and start Jupyter from this folder:

```bash
python -m pip install -r requirements.txt
jupyter notebook Shadrach_Oboh_Used_Car_Portfolio.ipynb
```
